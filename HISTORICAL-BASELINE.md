# HISTORICAL BASELINE — Ground Experience Portal

## Purpose

This is the single historical record for the cumulative Ground Experience Portal recovery. Historical Pxx/Rxx/e1 work remains traceable here, while valid implementation is merged into canonical runtime sources and retained regression coverage.

## Canonical consolidation rules

1. Historical files are evidence, not runtime architecture.
2. Valid functionality is merged into one canonical implementation; revision-labelled copies are not retained as parallel source.
3. Valid regression requirements are consolidated into `tests/canonical-regression.js` and the small set of non-revision build gates required by the current architecture.
4. Patch/diff/apply/rollback files are process artifacts and are not part of the website architecture.
5. Historical reports are not deleted conceptually; their relevant decisions are represented by this ledger.
6. Tests may describe intended behavior, but source/runtime behavior remains authoritative.
7. Later narrow changes must not overwrite unrelated previously-proven behavior unless a dependency is demonstrated.
